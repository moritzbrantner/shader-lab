Experiment ladder

Grow the model one boundary at a time

  1. 1Triangle

    Surface, device, WGSL entry points, pass, draw, present.

  2. 2Uniforms

    Move time, resolution, and pointer data from CPU to GPU.

  3. 3Buffers

    Make vertex data and memory layout explicit.

  4. 4Textures

    Introduce sampling, formats, filtering, and resource lifetime.

  5. 5Compute

    Separate general GPU work from rasterization and compare costs.

Native wgpu remains the reference path; browser experiments expose the same concepts through WebGPU without hiding the GPU boundary.
