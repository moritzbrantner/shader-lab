Mental model 01

A triangle is already a pipeline

Even the smallest GPU drawing crosses several boundaries. Shader Lab keeps those boundaries explicit so later buffers, uniforms, textures, compute passes, and WASM do not turn into unexplained machinery.

  1. 1Surface

    Choose where rendered pixels will be presented.

  2. 2Device

    Request the GPU capabilities needed by the experiment.

  3. 3Pipeline

    Bind shader entry points, formats, primitive state, and resources.

  4. 4Encode

    Record render commands into a command buffer.

  5. 5Submit

    Queue the work and present the resulting frame.

Lab rules

What counts as progress

  • Each experiment has one main question.
  • Pure shader and pipeline contracts are tested without requiring a physical GPU where possible.
  • Native and browser paths should share concepts and fixtures instead of silently diverging.
  • Performance claims need measurements, not intuition.
