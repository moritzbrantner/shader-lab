    Interpretation rule

    Capability evidence is not performance evidence.

    A large limit does not mean an operation is fast, and an adapter feature does not imply every browser/device pair behaves identically. Performance claims belong in explicit measurements with environment metadata.

    Use the live experiment
    Machine-specific adapter data is treated as canary evidence; deterministic repository tests should stay hardware-independent whenever possible.
